D. Ramya Sai Lakshmi - Portfolio Website
=======================================

Files
- index.html : the whole website (HTML, CSS and JavaScript in one file)
- photo.jpg  : your profile photo (replace with another square photo, keep the name photo.jpg)

Run it on your computer
Double-click index.html. It opens in your browser.

Edit it
Open index.html in VS Code. Search for the text you want to change
(bio, projects, links) and edit it.
- Project links: search for "View Code" and replace the GitHub profile link
  with the repo link of each project.

Deploy for free with GitHub Pages
1. On github.com click New repository, name it  ramya152004.github.io  (Public).
2. Click "uploading an existing file", drag in index.html and photo.jpg, then Commit.
3. Open Settings > Pages, choose Branch: main, folder: / (root), and Save.
4. After a minute your site is live at https://ramya152004.github.io

Netlify alternative: go to app.netlify.com/drop and drag the ramya-portfolio folder onto the page.
